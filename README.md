# Tabliczka mnożenia (PWA)

Pliki wgraj do repozytorium na GitHubie w tej samej strukturze:

- index.html
- manifest.json
- sw.js
- icons/ (icon-192.png, icon-512.png, icon-maskable-512.png)

Włączenie: Settings → Pages → Deploy from a branch → main / (root).
Adres: https://TWOJ-LOGIN.github.io/NAZWA-REPO/

Po zmianie plików podbij VERSION w sw.js (np. "v2"), żeby urządzenia pobrały nową wersję.
